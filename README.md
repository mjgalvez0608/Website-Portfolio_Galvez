# Website-Portfolio_Galvez

My personal portfolio website for class. I'm Mark Jaiden Galvez, 
a Computing student at Holy Angel University. The site has an overview of what I do, 
a short about section, my certificates, and my contact info.

Made with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - the main page
- `style.css` - styles for index.html
- `portfolio.html` - same page in one file (styles and images included)
- `mjg.jpg` - my photo
- `certs/` - certificate images

## Sections

- Home
- Overview
- About
- Projects & Certificates
- Contact

The projects part is still empty for now. I'll add them later.
